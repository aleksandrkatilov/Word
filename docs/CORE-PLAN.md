## 3. Что использовано повторно без изменений

`Pero.Core`: проверка пакета до чтения (`PackageInspector`, `BoundedReadStream`, `SafeXml`, лимиты), реестр совместимости, атомарная запись (`AtomicFileWriter`), автовосстановление (`RecoveryStore`), отпечаток файла для внешних изменений (`FileSnapshot`), последние файлы, политика ссылок (`LinkPolicy`), очистка HTML буфера обмена, отпечаток DOCX для сравнения (`DocxFingerprint`). Тесты `Pero.Core.Tests` (31), эталоны `samples/make_samples.py`, `Pero.Probe`, установщик Inno Setup, журнал `Log`, строки `Strings`.

Добавлено в `Pero.Core`: резервные версии `BackupStore` (REL-01, 20 версий на файл) и метка открытого файла `FileLock` (два экземпляра приложения).

## 6. Прототип открытия, правки и сохранения

Прототип — сама сборка из ветки `own-core`: открывает DOCX, правит текст и оформление, таблицы, изображения, колонтитулы, сохраняет с проверкой. Результаты автоматических прогонов — в ветке `ci-results` (журнал `lab.log`, таблицы `core/core-results.md`, `ui/ui-results.md`, скриншоты, сохранённые файлы).
