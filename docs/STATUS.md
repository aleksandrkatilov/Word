1. **Ключ лицензии Syncfusion → секрет `SYNCFUSION_LICENSE_KEY`** в настройках репозитория. Без ключа движок дописывает в каждый сохранённый документ строку «Created with a trial version…» и показывает окно лицензии при запуске. Это блокер для реального использования. Тесты сейчас вырезают эту строку перед сравнением.
2. **Решение по этапу 2** (раздел «Этап 2»): в движке нет исправлений, сносок, оглавления и закладок.

### Найденные и исправленные дефекты движка

- Вертикально объединённые ячейки: движок выбрасывал «продолжающие» ячейки, и в Word таблица распадалась. Исправлено в `EngineFixups`, подтверждено прогоном.
- Гиперссылки теряли стиль «Hyperlink». Восстанавливается.
- Скрытые части OOXML (customXml, пользовательские свойства) отбрасывались. Возвращаются при сохранении.
- Зависание при смене ориентации или полей: его вызывала проверка орфографии Windows во время пересчёта разметки (найдено перебором вариантов окна в CI). На время изменения макета она отключается.
- Двусторонняя привязка ползунка масштаба заменена односторонней синхронизацией.

- Линейки нет в движке (UI-07: изменение полей с линейки) — поля задаются на вкладке «Макет».
- Кнопки, добавленные на ленту кодом, не видны экранному диктору (движок не отдаёт их в UI Automation); встроенные кнопки и вкладка «Главная» видны.
- PDF вёрстает DocIO, а не экранная разметка — сравнить с печатью на эталонах (QA-02).
- Номер страницы в строке состояния — первая видимая страница, а не страница курсора.

## Этап 2 (P1) — что умеет движок (замер круговым обменом)

| Функция | Результат на SfRichTextBoxAdv 35.1 |
|---|---|
| Примечания | сохраняются ✓ |
| Разделы с разной ориентацией и колонтитулами | сохраняются ✓ (вставки разрыва раздела в движке нет) |
| Плавающие изображения с обтеканием | сохраняются ✓ |
| Орфография RU/EN | ✓ через словари Windows, свой словарь пользователя |
| **Исправления (track changes)** | ✗ движок молча принимает правки — документ открывается только для чтения |
| **Сноски, концевые сноски** | ✗ нет в модели движка |
| **Оглавление (TOC)** | ✗ код поля превращается в видимый текст — только чтение |
| **Закладки, перекрёстные ссылки** | ✗ теряются — только чтение |
| Подписи объектов, нумерация заголовков | списками — да; поля SEQ — нет |

**Вывод.** На этом движке этап 2 закрывается примерно наполовину. Варианты:

- **A. Остаться на Syncfusion** ($0). P1 без исправлений, сносок и оглавления. Документы с ними безопасно открываются только для чтения.
- **B. Перейти на DevExpress RichEditControl** (≈ $1 078 за разработчика в год). В нём всё перечисленное есть. Ядро, тесты, лаборатория CI, локализация оболочки и конвейер сохранения переносятся без изменений, оболочку переделать примерно за 1–2 недели. Лабораторию надо будет прогнать на нём тем же способом до покупки (у DevExpress есть пробная версия).
- **C. Гибрид**: редактирование в Syncfusion, а оглавление и сноски обновлять через DocIO при сохранении. Дёшево по лицензии, но хрупко и долго.

Рекомендация: **B**, если нужен полноценный P1; **A**, если важнее нулевая стоимость.
