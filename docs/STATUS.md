# «Перо» на собственном ядре — отчёт по ТЗ v2.3 (AC-08)

Ветка `own-core`. Всё, что отмечено «проверено», подтверждено автоматическими прогонами на виртуальной машине Windows Server 2025 в GitHub Actions (экран 1920×1080, DPI 100 %): журнал `lab.log`, таблицы `core/core-results.md` и `ui/ui-results.md`, скриншоты и сохранённые файлы лежат в ветке `ci-results`. Тесты ядра (`tests/Pero.Doc.Tests`, 57 проверок) проходят и на Windows, и на Linux.

Обозначения: **✓** реализовано и проверено · **◐** реализовано, проверено частично или без автоматической проверки · **△** ограничено · **✗** не реализовано.

## Главное

- Syncfusion полностью удалён: пакетов, ключей, окон лицензии, пробных надписей нет (проверка зависимостей `deps-check.md`, AC-07). Своё ядро `Pero.Doc`: модель, правка с отменой, разметка страниц, чтение и запись DOCX, шрифты, печать и PDF из одной разметки. Сторонних библиотек в приложении нет (только .NET 8, MIT).
- Корпус приёмки: 30 обычных + 10 сложных DOCX + эталоны + замеры, всего 55 файлов. Каждый открыт, размечен, изменён, сохранён с проверкой и открыт снова — потерь нет, весь текст размечен.
- UI-прогон: 22 сценария из 22 (ввод и формат, панель, линейки, таблица, ссылка, номер страницы, изображение, PDF, поиск, поиск команд, закрытие с изменениями, восстановление после сбоя, только чтение, два экземпляра, внешнее изменение, повреждённые файлы).
- Не проверено: открытие сохранённых файлов в Microsoft Word (на стенде нет Word) — нужен ручной прогон, см. «Что проверить вручную».

## 5. Ограничения (честно)

- **Word не проверялся** на стенде. Файлы пишутся по схеме OOXML, все исходные части переносятся байт в байт, LibreOffice и python-docx их открывают — но приёмку AC-02/REL-04 в Word нужно пройти вручную.
- Разметка близка к Word, но не идентична: нет переноса слов по слогам, контроля висячих строк, кернинга, плавающих объектов (надписи и обтекаемые рисунки показываются как есть в файле, документ открывается только для чтения), сносок и оглавления (открываются только для чтения).
- Внешняя вставка с оформлением (из Word/браузера) вставляет текст; оформление сохраняется при копировании внутри «Пера».
- Ширина столбца таблицы — через диалог; перетаскивания границы столбца мышью пока нет.
- Несколько разделов: поля и колонтитулы берутся из последнего раздела документа; файлы открываются и сохраняются без потерь, но разные поля разделов на экране не различаются.
- PDF встраивает шрифты целиком (файлы получаются крупнее, чем у Word).
- Печать использует тот же код рисования, что экран и PDF, но на реальном принтере не проверялась.

## 6. Что проверить вручную

1. Установить `Pero-Setup-*.exe` из артефактов последней сборки.
2. Открыть несколько своих документов Word, поправить текст, таблицу, вставить картинку, сохранить и открыть сохранённый файл в Microsoft Word — Word не должен предлагать восстановление.
3. Напечатать документ на принтере или в «Microsoft Print to PDF».
